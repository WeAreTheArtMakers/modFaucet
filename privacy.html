This notice covers the standalone modFaucet Chrome extension, version 0.10.0, and this download website. modFaucet is published by the GitHub account WeAreTheArtMakers.

What the extension reads

After you grant access, the extension reads supported PandaFaucet coin pages to observe reward quotes, visible claim controls, verification indicators, cooldowns and provider-reported completion messages. With separate FireFaucet approval, an explicit Read visible status request reads ACP, Fuel and native Auto Faucet session labels from supported official pages. These observations include a timestamp and page path; missing fields remain unknown. It uses the relevant tab identifiers and page paths to organize your selected coin pages.

It does not read passwords, input values, browser cookies, wallet keys, CAPTCHA tokens or the content of challenge frames. Flow query tokens are not saved. A page message is not an independently verified payment receipt.

Where data stays

Queue states, quotes, cooldown timestamps, tab identifiers, settings, FireFaucet observations and referral consent events are stored locally using Chrome extension storage. modFaucet has no collection server, telemetry service, advertising SDK or account database. This public edition does not connect to the desktop collector or require a native companion.

Permissions and alerts

Optional access is limited to https://pandafaucet.com/* and https://firefaucet.win/*, approved separately. FireFaucet has no background task completion or automatic status polling. Scripting reads supported pages in an isolated context; storage keeps local settings; alarms schedule checks; sidePanel displays the workspace; tabGroups organizes related tabs. Optional notification permission is requested only when you enable completion alerts. You can revoke website access in the panel or Chrome’s extension controls.

Referral links

The panel contains public referral signup links for FireFaucet, Final Autoclaim, Lightning Quest and MoonPTC. The publisher may receive commissions under those providers’ rules. Each link requires explicit, per-opening consent. The extension does not inject or replace referral codes in existing URLs or cookies, and it does not change payment destinations.

The provider may set its own cookies and determine attribution after you open a link. A local consent or link-open event does not verify registration or a referral relationship. A user’s rewards and the publisher’s commissions remain separate.

This website and GitHub downloads

This site loads its assets and release metadata from GitHub Pages. Downloads are served by GitHub Releases. No analytics, remote fonts, tracking pixels or marketing cookies are added by this website. GitHub processes requests under its own privacy notice. Clipboard access happens only when you choose a copy button.

Removing your data

Revoke access or pause monitoring from the extension panel. Removing the extension through Chrome removes its extension storage under Chrome’s normal removal behavior. Provider accounts and the provider’s own records are managed separately by each website.

Questions and support

Use the project’s GitHub issue page. Do not post passwords, wallet secrets, personal payment details or private account screenshots in public issues.
